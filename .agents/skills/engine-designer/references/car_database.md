Reference specifications for iconic performance cars and engine platforms.

## 1. American V8 Engines

### Chevrolet LS3 / LS7 90° V8
- **Displacement**: 6.2L (LS3) / 7.0L (LS7)
- **Bore x Stroke**:
  - LS3: 4.065" (103.25 mm) x 3.622" (92.0 mm)
  - LS7: 4.125" (104.78 mm) x 4.000" (101.6 mm)
- **Crankshaft**: Cross-Plane (90° journal offsets: 0°, 270°, 90°, 180°)
- **Firing Order**: 1-8-7-2-6-5-4-3 (Standard GM LS firing order)
- **Valvetrain**: Pushrod OHV, 2 valves per cylinder, 114° LSA
- **Redline**: 6,600 RPM (LS3) / 7,100 RPM (LS7)
- **Sound Character**: Deep, guttural, syncopated burble; heavy bass growl under load.

### Ford 5.2L "Voodoo" V8 (Shelby GT350)
- **Displacement**: 5.2L (5,163 cc)
- **Bore x Stroke**: 3.700" (94.0 mm) x 3.660" (93.0 mm)
- **Crankshaft**: Flat-Plane (180° journal offsets: 0°, 180°, 180°, 0°)
- **Firing Order**: 1-5-4-8-3-7-2-6 (or 1-4-3-8-2-5-7-6 depending on numbering)
- **Valvetrain**: DOHC 32-valve, high-lift cams
- **Redline**: 8,250 RPM
- **Sound Character**: Exotic, metallic, high-frequency scream; no classic cross-plane burble.

### Chrysler / Dodge 426 Hemi V8
- **Displacement**: 7.0L (6,981 cc / 426 cu in)
- **Bore x Stroke**: 4.250" (108.0 mm) x 3.750" (95.25 mm)
- **Crankshaft**: Cross-Plane (90° offsets)
- **Firing Order**: 1-8-4-3-6-5-7-2
- **Valvetrain**: Hemispherical combustion chambers, pushrod OHV
- **Redline**: 6,500 RPM
- **Sound Character**: Explosive, deep resonant thunder, hollow exhaust bark.

### Ford 302 / 351 Windsor V8
- **Displacement**: 4.9L (302) / 5.8L (351)
- **Bore x Stroke (302)**: 4.000" (101.6 mm) x 3.000" (76.2 mm)
- **Crankshaft**: Cross-Plane (90° offsets)
- **Firing Order**: 1-5-4-2-6-3-7-8 (302 standard) / 1-3-7-2-6-5-4-8 (351W / 5.0 HO)
- **Redline**: 6,000 RPM

## 2. European Exotics & Racing Engines

### Ferrari 458 Italia (F136 FB V8)
- **Displacement**: 4.5L (4,497 cc)
- **Bore x Stroke**: 3.700" (94.0 mm) x 3.190" (81.0 mm) (Over-square)
- **Crankshaft**: Flat-Plane (180° offsets)
- **Firing Order**: 1-5-3-7-4-8-2-6
- **Valvetrain**: DOHC 4 valves per cylinder, variable valve timing
- **Redline**: 9,000 RPM
- **Sound Character**: Crystalline, violin-like screaming tenor; instant throttle response.

### Porsche 911 GT3 (4.0L Flat-6)
- **Displacement**: 4.0L (3,996 cc)
- **Layout**: 180° Horizontally Opposed (Boxer 6)
- **Bore x Stroke**: 4.015" (102.0 mm) x 3.208" (81.5 mm)
- **Firing Order**: 1-6-2-4-3-5
- **Redline**: 9,000 RPM
- **Sound Character**: Raspy metallic howl, distinct high-rev flat-six resonance.

### Lamborghini Huracán / Audi R8 (5.2L V10)
- **Displacement**: 5.2L (5,204 cc)
- **Layout**: 90° V10 (Odd-fire split-journal crank)
- **Bore x Stroke**: 3.327" (84.5 mm) x 3.654" (92.8 mm)
- **Firing Order**: 1-6-5-10-2-7-3-8-4-9
- **Redline**: 8,700 RPM
- **Sound Character**: Distinctive howling wail with split-pulse acoustic timbre.

### Ferrari 3.0L Formula 1 V12 (Tipo 044/1 - 1995)
- **Displacement**: 3.0L (2,997 cc)
- **Layout**: 75° V12
- **Bore x Stroke**: 3.465" (88.0 mm) x 1.614" (41.0 mm) (Extreme short stroke)
- **Redline**: 17,000 RPM
- **Sound Character**: Ultra-high register, piercing operatic scream.

## 3. Japanese Performance Engines

### Toyota Supra 2JZ-GTE (Inline-6)
- **Displacement**: 3.0L (2,997 cc)
- **Bore x Stroke**: 3.386" (86.0 mm) x 3.386" (86.0 mm) (Square)
- **Crankshaft**: 120° journal offsets (0°, 120°, 240°, 240°, 120°, 0°)
- **Firing Order**: 1-5-3-6-2-4
- **Valvetrain**: DOHC 24-valve
- **Redline**: 7,200 – 8,500 RPM
- **Sound Character**: Silky smooth straight-six buzz, rich third-order harmonics.

### Mazda 787B 26B (4-Rotor Wankel Rotary)
- **Displacement**: 2.6L (4 x 654 cc rotors)
- **Eccentric Shaft**: 90° phasing between rotors
- **Firing Frequency**: 1 power stroke per rotor per revolution (4 pulses/rev, like an 8-cylinder 4-stroke)
- **Redline**: 10,500 RPM
- **Sound Character**: Unmistakable bee-swarm electronic buzz; rapid rev transitions.
