# Engine Simulator Automated Recording Instructions
# ----------------------------------------------------
# Lines starting with '#' or '//' are ignored.
#
# Supported instruction formats:
#   1. Natural text:
#      record the engine file <engine> on RPM <rpm> for <duration> seconds
#      record <engine> at <rpm> rpm for <duration>s
#   2. Shorthand:
#      <engine>: <rpm> RPM, <duration>s
#   3. Comma-separated:
#      <engine>, <rpm>, <duration>
#
# Optional overrides: [throttle=w] (10%), [throttle=e] (20%), [throttle=r] (100% full throttle - default)
#                     [out=custom_name.wav]
#
# Examples:

record the engine file assets/engines/mercedes/sls_amg_gt3_m159.mr on RPM 4000 for 3 seconds
record assets/engines/atg-video-2/03_2jz.mr on RPM 6000 for 3 seconds
record assets/engines/musical/musical_v8.mr on RPM 3300 for 3 seconds [throttle=r]
record assets/engines/atg-video-2/10_lfa_v10.mr on RPM 8000 for 3 seconds
